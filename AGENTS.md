# Правила проекта «Моя полка»

- React + TypeScript + MUI. Оформление через theme и sx; MUI явно выбран пользователем вместо рекомендации Tailwind из регламента.
- Перед нетривиальной реализацией согласовать план. План текущей задачи #1 утверждён пользователем.
- Изменения делать в feature/<номер-задачи>-<описание>; main обновлять только через PR после ревью и успешного CI.
- Не менять общую историю. Синхронизировать собственную работу через pull --rebase; не обходить хуки.
- Перед каждым коммитом читать git status и полный diff, затем добавлять конкретные файлы.
- Строгие типы, без any и мутации props/параметров. У собственных функций явно указывать возвращаемый тип.
- Компоненты в src/components, типы в src/types, работа с хранилищем в src/storage. Импорты MUI направлять на конкретные компоненты.
- Форма и список используют React state. localStorage читается и записывается только по соответствующим кнопкам; входящий JSON валидируется как unknown.
- Не добавлять несвязанные изменения. Пользователю объяснять работу простым русским языком.
- Изменённое поведение покрывать тестами. До PR запускать npm run check, проверять браузер и прочитывать полный diff.
- Не коммитить .env, node_modules, dist, отчёты и локальные данные. Не читать и не публиковать секреты.
