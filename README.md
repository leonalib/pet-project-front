# Пет проект

Локальный фронтенд на React, TypeScript и Vite.

## Запуск

Используется Node.js 24.

```sh
git clone https://github.com/leonalib/pet-project-front.git
cd pet-project-front
npm ci
npm run dev
```

Адрес для просмотра появится в терминале. Обычно это http://localhost:5173.

## Команды

- `npm run dev` — запуск для разработки с автоматическим обновлением.
- `npm run build` — проверка TypeScript и сборка в dist/.
- `npm run lint` — проверка кода через Oxlint.
- `npm run preview` — локальный просмотр готовой сборки.

## Основные файлы

- src/App.tsx — основной компонент приложения.
- src/App.css — стили основного компонента.
- src/index.css — общие стили.
- src/main.tsx — точка входа React.
